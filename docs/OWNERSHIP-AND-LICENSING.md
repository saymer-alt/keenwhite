# KeenWhite: происхождение кода и лицензии

**KeenWhite — самостоятельный репозиторий и поддерживаемый проект saymer-alt, НЕ GitHub fork.** Самостоятельность проекта не означает, что весь код в нём является оригинальным.

## Обязательные условия

| Часть | Источник | Лицензирование | Политика |
|---|---|---|---|
| `cmd/`, `internal/`, `examples/`, собственные `docs/`, адаптеры | Новая реализация KeenWhite | MIT (корневой `LICENSE`) | Можно изменять как оригинальный код KeenWhite |
| `transports/wdtt/` (ПОКА НЕ ИМПОРТИРОВАНО) | `saymer-alt/wdtt-suite`, форк `hoaxisr/proxy-turn-vk-android` | GPL-3.0; точные upstream notices и зависимости сохранять | Импортировать с Git-историей и исходным `LICENSE`. Все изменённые производные файлы сохраняют соответствующие условия; не переименовывать происхождение |
| OpenFlux, если решим импортировать его исходники | `p1neappleXpress/OpenFlux` | GPL-3.0 | По умолчанию только независимый процесс + наш адаптер; любое включение кода — отдельное лицензионное решение |
| CSQTT | `amurcanov/csqtt` | PolyForm Noncommercial 1.0.0 (см. конкретную ревизию) | Не копировать в MIT/GPL части без отдельной проверки условий распространения |
| Swinter / MAX | upstream и их vendored dependencies | Требует файлового аудита (есть Unlicense и зависимости иных лицензий) | Архитектуру можно изучать; копирование только после provenance-аудита |
| WhiteTransport / whitelist-bypass | соответствующие upstream | Проверять по каждому компоненту | Референсы, не blanket-права на код |

Пока WDTT расположен в **другом GitHub-репозитории**, KeenWhite может ссылаться на него, но **не имеет права объявлять этот код перенесённым**. После импорта должен появиться `transports/wdtt/LICENSE`, original notices, исходный commit SHA и понятная карта файлов.

Для GPL-компонентов отдельно отслеживать лицензии сборочных зависимостей и условия распространения. MIT-лицензия корня относится к файлам **оригинального KeenWhite**; она не отменяет обязательств по другим исходным лицензиям. Если позже появится единый бинарник с включением GPL-кода, отдельно определить лицензирование результирующей производной программы, а не считать, что граница каталогов автоматически гарантирует совместимость.

Не присваивать авторство upstream-разработчиков. Не удалять их историю, copyright notices и сторонние licenses при рефакторинге. Файл с приватным профилем, VK/MAX auth, cookies, short-password link, HWID либо token **никогда** не добавлять в Git.
